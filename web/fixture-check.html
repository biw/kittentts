Browser Fixture Check

This page runs one saved KittenTTS fixture chunk in the browser using onnxruntime-web. It requests webgpu first and falls back to wasm if needed. Use ?pipeline=fixture for saved feeds, ?pipeline=phonemizer-js to rebuild browser phonemes and token IDs from the fixture chunk text, or ?pipeline=full-js to rebuild the full browser path from raw case text before inference. Add &execution=wasm to force the simplest correctness path while debugging or automating the page.
